# あなたの節目の年

生年月日を入れると、これまでとこれからの「**節目の年**」が出ます。出生時刻はなくても使えます。

👉 **https://kira-ring777.github.io/turning-points/**

## 出るもの

- **木星が戻ってくる年**（12年に一度）
- **土星が戻ってくる年**（30年に一度）
- **キロンが戻ってくる年**（50歳前後・一生に一度）
- **進めた太陽が星座を移る年**
- **進めた太陽が、生まれたときの天体に届く年**（水星〜冥王星・ドラゴンヘッド）
- 生まれた時間がわかる方は、**月・アセンダント・MCに届く年**も

## 計算について

「進めた」は**ソーラーアーク法**です。生まれたあとの太陽が実際に動いた分だけ、出生図をまるごと同じ度数だけ動かします（1年に約1度）。

見ている角度は3つ。**重なる**（0度）・**直角になる**（90度）・**向かい合う**（180度）。オーブは0.5度なので、書かれた年の**前後およそ半年**が効く幅です。

ドラゴンヘッドは**平均交点（Mean Node）**で計算しています。

天体の位置は [Swiss Ephemeris](https://www.astro.com/swisseph/) で算出したデータを使っています。

## 読み方

この一覧に出るのは「**いつ星の節目が来るか**」だけです。その年にどんなテーマが動くのか、過去の節目でどう答え合わせをするのかは、記事にまとめています。
